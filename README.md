# Учебные проекты C#

Небольшие примеры работы с числами, файлами и Windows-интерфейсами.

| Приложение | Платформа | Интерфейс |
| --- | --- | --- |
| ComplexNumbers | .NET 10 | Консоль; [документация](ComplexNumbers/README.md) |
| Capitals | .NET 10 | WinForms и WPF на общей библиотеке |
| TextEditor | .NET 10 | WinForms и WPF на общей библиотеке |
| MoreLessProgram | .NET Framework 4.5.2 | Консоль |
| FilenameExtension | .NET Framework 4.5.2 | Консоль |
| TreeOfDir | .NET Framework 4.5.2 | Консоль |

Десктопные проекты объединены в `Desktop.slnx`.
Сборка, запуск, тесты и изменения поведения описаны в [DESKTOP.md](DESKTOP.md).
Консольные файловые утилиты будут обновляться отдельно; они могут записывать
или удалять файлы, поэтому проверять их следует только на тестовых данных.

SQL-скрипты в корне — отдельные учебные материалы для SQL Server.
